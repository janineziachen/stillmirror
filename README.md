## 这个产品在解决什么问题

在心理咨询机构工作的这些年，我反复遇到同一类人。

有一个来访者让我印象很深。她是互联网公司的中层，第一次来的时候说"我也不知道自己算不算有问题"。她能正常上班、正常社交，但每天晚上躺下来的时候会觉得胸口压着什么东西。她做过网上的抑郁量表，得分在"轻度"和"中度"之间反复横跳，但她不认为自己需要"看病"。

还有一类更沉默的人。他们连咨询室的门都不会推开。一个大学生在学校心理普查中所有选项都选了"正常"，三个月后室友发现他在连续失眠。事后他说："那些题目让我觉得选了不好的选项就会被叫去谈话，我不想被当成有问题的人。"

这两类人代表了心理健康服务中最大的断层地带——他们有感知，但没有行动；有需求，但不信任现有的触达方式。

**心镜想做的事情是：让这些人在不需要承认"我有问题"的前提下，完成一次真实的心理接触。**

## 为什么是一个"游戏"

这群人的核心特征是：高防御、高感知、低行动。他们对"被分析"极度敏感，任何带有评估意味的交互都会触发自我保护。但他们同时又渴望被理解——只是这个"理解"不能以审视的姿态出现。

游戏（更准确地说，互动叙事体验）天然解决这个矛盾：

- **安全的距离感**：用户操作的是隐喻世界中的角色，而不是直接面对自己。在花园里选择"坐在湖边不动"，比在量表上勾选"我经常回避问题"要容易得多——虽然它们观察的是同一件事。
- **主动参与**：用户不是在被测试，而是在探索。每一次点击都是他们自己的选择。
- **承载节奏**：心理干预中最被低估的要素是"时间"——给人留白、让情绪有空间浮现。在游戏中，一段缓慢的画面转场、一次刻意的停顿，都是合理的、甚至是美的。

## ACT 框架与六个场景

接纳承诺疗法（ACT）的核心不是要求用户改变想法，而是改变与想法的关系。它的哲学内核是：痛苦不是需要消灭的敌人，而是生命的一部分；真正的自由不是"感觉好"，而是"即使感觉不好，依然能朝重要的方向迈步"。

心镜将 ACT 的六大核心过程转化为六个叙事场景：

| 场景 | ACT 维度 | 隐喻 |
|------|----------|------|
| 湖 | 接纳 | 面对水中倒影——愿意与不舒服共处，还是转身离开？ |
| 天空 | 认知解离 | 天空中飘过的云——它是"事实"，还是"只是一个想法"？ |
| 小径 | 当下觉察 | 脚边不起眼的花——注意力在此刻，还是被过去/未来牵引？ |
| 古树 | 以己为景 | 刻满痕迹的老树——能从旁观者视角看待经历，还是被经历淹没？ |
| 花圃 | 价值澄清 | 四颗不同的种子——你真正在乎什么？ |
| 桥 | 承诺行动 | 看不清尽头的桥——即使不确定，愿意迈出一步吗？ |

六个场景结束后，系统生成一座专属的四季花园。心理灵活性高的维度呈现为春天，困难的维度呈现为冬天——但冬天不被标记为"问题"，它被描述为"正在等待的土地"。

## 设计哲学

**隐喻即评估。** 用户体验到的是诗意的叙事，系统完成的是心理画像。这两层同时发生，互不干扰。

**节奏即干预。** 产品刻意采用慢节奏——图片缓慢浮现，文字逐行显现，场景之间留有呼吸的黑屏。用户在体验产品的过程中，已经在进行一次微型的正念练习。

**去病理化表达。** 全程不出现"障碍""症状""治疗"等词汇。低分不意味着"有问题"，而意味着"这里需要更多的温柔"。

## 我的思考

我相信 AI 在心理健康领域最大的价值不是"模拟专家"，而是"降低门槛"——让专业内容以更低防御、更高触达、更美的形态抵达那些原本不会主动寻求帮助的人。

心镜中，AI 的角色是内容生产者和个性化引擎，而不是"治疗师"。心理学框架的严谨性、干预建议的专业校准、伦理边界的把控，始终由人来完成。

这个项目是我对"AI 如何正确进入心理健康领域"这个命题的一次回答。
